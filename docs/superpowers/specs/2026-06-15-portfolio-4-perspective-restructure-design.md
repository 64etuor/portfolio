## 1. 목표

기존 **5막 서사**(현장→측정→시스템→운영→자율→사람) 분류축을 **4관점**으로 교체하고, 27개 시안의 콘텐츠를 전면 재작성한다.

- **단일 축**: 5막 SECTIONS를 4관점이 완전히 대체. (두 번째 축 공존 아님)
- **한 시안 = 하나의 관심사**: 콘텐츠를 다시 쓰면서 현재의 겹침을 분리. 기존 "지표 owner 1:1" 원칙을 *관심사 전체*로 확장.
- **27개 비주얼 셸 유지**: HTML 메타포 자산은 버리지 않고 재배치 + 재작성. (활성 22 / 보류 5)

## 6. 제약 / 금지

- **브랜드/실명 비표기**: 뷰티 매장 SW 제품 브랜드명 삭제(뷰티 매장 운영 SW로 일반 서술). 이전 직장 프로젝트명 완전 제외. DB 스킬 시안(#22)은 실제 프로젝트명 대신 유명·장대한 DB 예제 사용.
- **글·시·에세이 제외**: 철학은 일하는 사고원칙만. 문필가 프레임 폐기.
- **지표 owner 1:1**: 한 지표가 여러 시안에 중복되지 않게. 모든 지표는 프로젝트+경력 관점.
- **로컬 전용·push 금지**: 원격 없음. 사용자 지시 없으면 push 불가.
- **인트로 의존성**: reel.json·registry 동기화 필수. durationMs는 실제 애니 길이 기준.
