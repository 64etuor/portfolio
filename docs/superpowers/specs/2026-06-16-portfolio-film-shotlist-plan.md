## B. 막별 샷리스트
형식: 진입컷 → 그레이딩/카메라 → 비트(시안·자막) → 퇴장 매치컷 → 사운드. (타이밍은 릴 기준 권장초)

### 00 · 부팅 (v0) · ~6s
- 진입: 암전, 단일 기준선 1개.
- 자막(로그체): `시대는 빠르게 변한다.` → `사람도 변해야 한다.` (작게 흐름)
- 비트: 05 BIOS/POST를 *영사기 점등*으로. 무채색·정지.
- 퇴장 매치컷: **기준선 → 금속 절단면**.
- 사운드: 팬·릴레이 딸깍, 비프 1.

### 1막 · 은성 2020 (v1) · ~14s
- 진입: 금속 표면 위 생산 라인이 얇게 새겨짐.
- 그레이딩: 냉간 금속·형광등·검사유리 반사 / 카메라 오버헤드·정면 고정.
- 비트:
  - A `20 계측랙` — 생산관리·원가를 데이터로 본 첫 시도. 자막 `원가를 숫자로 세운다`
  - A 비전검사 도입(누락·역삽 방지). 자막 `사람 눈 대신 카메라로 본다`
  - B `08 스프레드시트` — 엑셀 자동화 = 코딩의 출발(스파르타 학습). **"없는 도구의 음영"**: 빈 자동화 자리 → 매크로로 채움.
- 퇴장 매치컷: **비전검사 박스 코너 → 용접 지그 고정점**.

### 2막 · 이랜텍 2022 (v2) · ~20s (B 스크롤 포함, 가장 김)
- 진입: LOB 차트가 실제 공정 레일로.
- 그레이딩: 약간 뜨겁게(과장 금지) / 매크로·고속셔터·손 트래킹.
- 비트:
  - **B `02 어셈블리`(스크롤 심화)**: ①진단(C/T·LOB 불균형) ②병목 ③개입(레이아웃: 조립/SMT 분리→복합·원더풀 라인 증설, Jig) ④검증(생산성 +24%) ⑤사고원칙(`불합리를 측정 가능한 병목으로 환원, 가장 큰 제약부터`)
  - A `18 용착`+`11 용접` — 저항/레이저(Nd:YAG)/초음파 **접합 방식 차이**. 자막 `세 가지로 붙인다` (용착 15→0%는 작은 눈금)
  - A `16 로봇티칭` — PLC 단축로봇·취출로봇 31대 개조·엔드밀 사상 JIG.
  - A `15 SCADA` — 창고 물류 개선(재고회전율 +17% 눈금).
  - A `07 프린터→Jig` — 적층 3D 비주얼 + 카트리지형 컷팅/누름 Jig 직접 내재화(외주→사내). **3D 효과 여기 집중.**
- 퇴장 매치컷: **지그 구멍 배열 → DB 테이블 PK 점**.

### 3막 · 솔라엣지 2023 (v3) · ~18s (빌더 전환점)
- 진입: 엑셀 셀이 **깨지지 않고 정규화**→관계형 테이블 경계로 재배열.
- 그레이딩: 흰·회·녹 데이터 신호, 금속 후퇴 / 탑뷰→ERD 진입.
- 비트:
  - A `01 MES` — 본인 작성 스펙시트·OPC UA·PostgreSQL·계층형 S/N 바코드. 자막 `예산에서 빠진 칸을 직접 코딩했다`
  - A `12 추적성` — Power Platform 앱·카메라 S/N 스캔·SN 유효성/인터락.
  - A `22 DB모델링` — 19테이블 정규화 ERD·EBOM→MBOM 다단계 전개.
  - B 시스템 빌드 심화 — 엑셀→DB→MES→추적성. **"없는 도구의 음영"**: 빈 DB 자리·빈 추적성 자리 → 시스템으로 채움.
  - (검사 데이터 엔지니어링: OCV/IR·Waterpouch 2D 광학측정 데이터 수집·Cpk 시각화 — 12에 흡수)
- 퇴장 매치컷: **ERD 관계선 → 코드 편집기 커서**.

### 4막 · 역량 보강 2024 (v4) · ~10s (전환 아님, 장착)
- 진입: 제조·데이터 레이어 위에 SW 레이어 **추가**(기존 안 지움).
- 그레이딩: 가장 건조·중립 / 노트·터미널·강의·프로토타입 교차.
- 비트:
  - B `06 디지털 트윈`(재정의) — 제조+데이터+AI 도메인 연결 = 조직/공정의 트윈 → 사일로 커뮤니케이션 오류·경계 문제 미식별 해소. 자막 `도메인을 연결하면 안 보이던 문제가 보인다`
  - A `04 semantic map` — 학습/지식 맵(메타코드 데이터분석·한화 Beyond SW, 초록 부트캠프).
- 퇴장 매치컷: **터미널 커서 → ALB health check trace**.

### 5막 · 스타트업 2025 (v5) · ~20s (클라이맥스, 관제실 시선)
- 진입: 시스템 맵 부팅.
- 시선: 무엇이 터지고·감지하고·복구하는가.
- 비트:
  - A `19 토폴로지→인프라` — ECS·ALB·Terraform·Sentry/CloudWatch 관제. **"없는 도구의 음영"**: 빈 관제 자리 → 채움.
  - A 백엔드(FastAPI)·CRM(React)·키오스크(Electron) — *미러리스 구멍: 보류*(임시로 간트 detail/단신 placeholder).
  - A `03 Notion OS` — 조직 운영 OS.
  - A `23 Boule`·`25 Decision OS`·`26 GraphRAG(축소)` — AI 거버넌스(권한·중단조건·인간승인).
  - B 운영 루프 심화 — 직접 만든 시스템들이 하나의 표면에서 연결.
- 퇴장 매치컷: **CloudWatch trace가 수평으로 펴지며 간트 막대**.

### 에필로그 · now — Work Radar · ~8s
- 진입: `now` + 기준선 다시 불안정.
- 비트: A `13 Work Radar` 개인 AI 콕핏 = 다음 버전 작업대. 자막 `다음 버전은 아직 빌드 중`
- 퇴장: Work Radar sweep 1바퀴 → 모든 기준선이 시간축으로 정렬 → **피날레로**.

### ★ 피날레 · 간트 펼침 → 인터랙티브
- 앞 막의 모든 선(라인·용접선·ERD·커서·trace·sweep)이 같은 방향으로 누움 → 카메라 풀백 → 회사 lane + 핵심 작업 = 막대. **17 자산 그대로 재사용**(카운트업·막대채움·크리티컬패스 = 펼침 애니).
- 막대 클릭 → **고정 검증 패널**: `① 문제 / ② 직접 만든 도구 / ③ 사용 기술 / ④ 운영·개선 증거 / ⑤ 관련 장면 되감기(해당 막으로)`.
- 자막 `이제 직접 확인하세요.` → 자동재생 종료, 사용자 운전. CPM = 커리어 critical path(제조 기준 → 데이터 무결성 → 시스템 운영 → AI 거버넌스).
- 옵션: 막대 클릭 시 **검증 리플레이 7초**(문제2·도구3·증거2).

## D. 구현 단계 (build order)
- **Phase 0 · 영화 셸**: 기준선 레이어·버전HUD·자막·트랜지션 엔진·릴 컨트롤러·Skip. 새 `/` 라우트. (기존 index 대체)
- **Phase 1 · 피날레 먼저**: 17 간트 재사용 + 검증 패널 5필드 + 되감기 링크. → Skip 경로가 즉시 작동(채용담당자용 도착지 확보).
- **Phase 2 · 골격**: 부팅 + 막 진입/퇴장 매치컷 페어 + 시안 임베드 순서(콘텐츠는 임시).
- **Phase 3 · 콘텐츠**: 막별 시안을 실자료로 수정(Type A/B), "없는 도구의 음영"·로그체 자막 적용. (용접·로봇 디테일은 SME 확인 후)
- **Phase 4 · 폴리시·검증**: 사운드, prefers-reduced-motion, 헤드리스 렌더(JS 에러 0)·빌드 그린.

리듬: 짧은 A 단신 사이에 B 스크롤 심화(2막 어셈블리·3막 시스템빌드·4막 트윈·5막 운영루프)를 끼워 호흡.
