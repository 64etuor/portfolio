## 1. 테제 (단일 척추)
- **모토**: "시대는 빠르게 변한다. 사람도 변해야 한다."
- **빌더 라인**: "도구가 없으면 직접 만들었다." — 지표는 **증거**일 뿐 헤드라인이 아니다.
- 이 커리어는 "전직"이 아니라 **기준을 새로 잡는 방식의 누적**: 현장 물리 기준 → 데이터 무결성 기준 → 시스템/AI 운영 기준을 직접 세움.

## 2. 단일 비주얼 모티프 — 기준선(datum line)
화면을 관통하는 선 하나가 역할을 바꾸며 영화를 묶는다:
`공정 레일·캘리퍼 눈금·용접 지그 가이드선 → DB 관계선 → 코드 커서 → 인프라 trace → (피날레) CPM 간트 시간축`
- 모토/빌더 라인은 **선언하지 않는다.** 선이 매번 다른 도구로 기능하면 증명된다.
- 상시 표시는 선 + **버전 카운터 `v0→v5→now`** 만. 지표는 선 위 작은 눈금으로만, 클릭 시 증거로 펼침.

## 3. 시안 2종 아키타입
- **Type A · 포커스 단신**: 1기법 = 1화면, 밀도 높은 전문 카드. (용접·로봇티칭·MES·추적성 등)
- **Type B · 스크롤 심화**: 단계적 방법론을 스크롤로 전개, **사고방식이 척추**. (어셈블리 LOB·도메인 연결·시스템 운영 루프)

## 4. 막 구성 (부팅 + 5막 + 에필로그)
배치 밀도: `부팅1 / 1막3 / 2막3 / 3막4 / 4막2 / 5막5 / 에필1`. 내레이션 없음 — 자막은 **정비 매뉴얼·로그·커밋 메시지체**로 건조하게.

### 00 · 부팅 (v0)
검은 화면의 단일 기준선. `v0` + 로그처럼 흐르는 "시대는 빠르게 변한다. 사람도 변해야 한다." 무채색·정지 카메라. 우상단 **`Skip to Gantt`** 상시.
→ 매치컷: 기준선이 금속 절단면으로.

### 1막 · 은성 2020 (v1) — 손의 시대, 그러나 이미 정렬을 시작
- 그레이딩: 냉간 금속·형광등·검사 유리 반사. 카메라 오버헤드/정면 고정.
- **A**: 생산관리·원가(20 계측랙), 비전검사 도입. **B**: 스마트팩토리 ERP가 현장 흐름을 묶는 골격(완성 대시보드 아님).
- 콘텐츠(실자료): 원가/재공 구조를 데이터로 본 첫 시도, 비전 시스템(누락·역삽 방지) 도입.
- **08 코딩의 기원**을 여기 배치: 엑셀 자동화 = 코딩의 출발(스파르타 학습과 연결).
→ 매치컷: 비전검사 박스 코너 → 용접 지그 고정점.

### 2막 · 이랜텍 2022 (v2) — 라인·접합·지그
- 그레이딩: 금속보다 약간 뜨겁게(과장 금지). 매크로·고속셔터·손 트래킹.
- **B 어셈블리(02)**: LOB·DMAIC 방법론 → 실제 레이아웃 변경(조립/SMT 공간 분리 → 복합라인+원더풀 조립라인 증설, 동선 단축, 기능검사기 BIC/BCU/CS).
- **A**: 용접 3종(18/11) = 저항·레이저(Nd:YAG)·초음파 **접합 방식의 차이**(스파크쇼 아님); 로봇티칭(16) = PLC 단축로봇·취출로봇 31대 개조·엔드밀 사상 JIG; SCM 재고(15) = 창고 물류 개선 과제.
- **07 프린터→Jig(부활)**: 적층제조 3D 비주얼 + **Jig 직접 내재화**(카트리지형 컷팅/누름 JIG, 외주→사내, Insert 자동화 JIG).
→ 매치컷: 지그 구멍 배열 → DB 테이블 PK 점.

### 3막 · 솔라엣지 2023 (v3) — 빌더의 전환점 (직접 구축)
- 그레이딩: 흰·회·녹 데이터 신호, 금속 질감 후퇴. 탑뷰 → ERD 안으로 진입.
- 진입: 엑셀 셀이 **깨지지 않고 정규화**되어 관계형 DB 테이블 경계로 재배열.
- **A**: ① 공정데이터 시스템(VBA 무결성·CountIfs 중복차단·auto PK·DAX/Power BI 3-Phase) ② MES 자체개발(본인 작성 스펙시트·OPC UA·PostgreSQL·계층형 S/N 바코드) ③ 추적성 앱(Power Platform·카메라 S/N 스캔·SN 유효성/인터락) ④ DB 모델링(22, 19테이블 정규화 ERD·EBOM→MBOM 다단계 전개).
- **B**: 엑셀 → 관계형 DB → MES → 추적성으로 이어지는 "직접 만든 시스템" 심화 스크롤.
→ 매치컷: ERD 관계선 → 코드 편집기 커서.

### 4막 · 역량 보강 2024 (v4) — 전환이 아니라 장착
- 그레이딩: 가장 건조·중립. 노트·터미널·강의·프로토타입 교차.
- **B 06 디지털 트윈(재정의)**: 제조·데이터·AI 도메인이 한 사람 안에서 **연결 → 조직/공정의 디지털 트윈처럼 작동** → 사일로 커뮤니케이션 오류·경계 문제 미식별을 해소. **A 04**: 학습/지식 맵.
→ 매치컷: 터미널 커서 → ALB health check trace.

### 5막 · 스타트업 2025 (v5) — 전부 직접 (클라이맥스)
- 시선: 제품 홍보샷 아님, **관제실의 시선**(무엇이 터지고·무엇이 감지하고·무엇이 복구하는가).
- **A**: 인프라(19→ECS·ALB·Terraform·Sentry/CloudWatch 관제), 백엔드(FastAPI), CRM(React), 키오스크(Electron), Notion OS(03), AI 거버넌스(23 Boule·25 Decision OS·26 GraphRAG 축소).
- **B**: 직접 구축한 시스템들이 **운영 루프**로 연결되는 심화 스크롤.
- ⚠️ CRM·백엔드·키오스크앱·키오스크HW 전용 시안 부재 → **신규 제작 vs 간트 흡수**(미러리스 파트, 별도 결정·보류).
→ 매치컷: CloudWatch trace가 수평으로 펴지며 간트 막대.

### 에필로그 · now — Work Radar (13)
완성 선언 아님. `now` + 기준선이 다시 불안정. 개인 AI 콕핏 = 다음 버전의 작업대. 가장 선명·가장 덜 장식적.
→ Work Radar sweep 한 바퀴 → 모든 기준선이 시간축으로 정렬.

## 5. 피날레 — "간트 펼침" → 인터랙티브 검증
앞 막의 모든 선(라인·용접선·ERD·커서·trace·sweep)이 같은 방향으로 눕는다 → 카메라 풀백 → 회사별 lane + 핵심 작업 = **간트 막대**(이미 구현된 17 자산 재사용: 카운트업·막대 채움·크리티컬 패스 = 그대로 펼침 애니).
- 막대 클릭 → **고정 검증 패널**: `① 문제 / ② 직접 만든 도구 / ③ 사용 기술 / ④ 운영·개선 증거 / ⑤ 관련 장면 되감기`.
- CPM = "가장 오래 걸린 일"이 아니라 **커리어 critical path**(제조 기준선 → 데이터 무결성 → 시스템 운영 → AI 거버넌스).
- 자막 "이제 직접 확인하세요." → 영화가 **이력서**가 됨. 관객 = 검증자.

## 6. 파격 장치 3개 (codex)
1. **무음 로그체 자막** — 내레이션 제거. 정비 매뉴얼·커밋 메시지처럼 건조할수록 신뢰↑.
2. **"없는 도구의 음영"** — 만든 도구 보여주기 전, **비어 있던 자리**부터(빈 DB 자리·빈 추적성 자리·빈 관제 자리) → 그 빈칸이 실제 시스템으로 채워짐. "도구가 없으면 만들었다"의 시각적 증명.
3. **검증 리플레이 7초** — 막대 클릭 시 문제2초·도구3초·증거2초의 차가운 감사 기록.

### 검사 수단 (3D 검사 재설계)
CMM·3D 스캐너·머신비전 **직접 제작 증거 없음**. 실제 = OCV/IR 전기검사 + Waterpouch **2D 광학측정**(Distance/Angle vs 스펙) 데이터 **수집·DB통합·시각화(Cpk)** + 수기 체크시트 전산화.
→ "3D 검사"는 **검사 데이터 엔지니어링**으로 재프레이밍(12/Waterpouch). **3D 시각효과는 07 프린터/Jig(적층제조)로 이전** — 실제 제작 영역.
