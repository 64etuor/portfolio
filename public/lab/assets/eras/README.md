# SCENE 01 — 시대 사진 (era photos)

`42-era-shift.html`("시대는 빠르게 변하고 있습니다")가 이 폴더의 사진을 빠르게 넘기는 몽타주로 사용합니다.

## 사진 넣는 법
- 파일명을 **`01.jpg`, `02.jpg`, `03.jpg` …** 로 해서 **시대순(오래된 → 최신)** 으로 이 폴더에 넣으세요.
- 그러면 코드 수정 없이 자동으로 잡힙니다 (`01.jpg`~`12.jpg` 중 있는 것만 사용, 없는 번호는 건너뜀).
- **권장:** 가로 16:9 사진. 너무 밝아도 씬에서 어둡게 그레이딩되니 OK.

## 다른 파일명/포맷(png 등)을 쓰려면
`42-era-shift.html` 상단의 `PHOTOS` 배열을 직접 수정하세요. 예:
```js
const PHOTOS = [
  'assets/eras/mainframe.png',
  'assets/eras/pc.jpg',
  'assets/eras/mobile.jpg',
  // …시대순으로
];
```

사진이 하나도 없어도 어두운 플레이스홀더 슬라이드로 정상 재생됩니다.
