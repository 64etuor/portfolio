공정 데이터 수집 → 정규화 DB → Power BI 파이프라인

            
엑셀 파편화(생산일보·공수·불량 각개 관리) 안티패턴을 제거. PostgreSQL 정규화 DB(1NF/2NF/3NF)에 단일 입력하고, 자체개발 MES가 OPC UA 설비 데이터와 계층형 S/N 바코드를 연결 — Power BI에서 공수·생산현황·불량 리스크 범위를 투명하게 집계.

          

          

            
            
          

        


        

          

          

            

              
✗ anti-pattern

              
엑셀 파편화: 생산일보·공수·불량을 각기 다른 파일로 관리 — 집계 오류·중복·추적 불가.

            

            

              
정규화 설계 근거

              
1NF/2NF/3NF 준수. PK/FK 명시, UNIQUE·partial index·CHECK 제약으로 중복과 상태 오류를 DB 레벨에서 차단.

              1NF/2NF/3NFPK/FKPostgreSQL
